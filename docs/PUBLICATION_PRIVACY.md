# 公开版本的隐私处理

公开候选版本已对全部 16 个分支、124 个原始提交进行脱敏：实际内网地址改为文档专用地址，个人电脑路径改为占位符，SSH 密钥文件名改为通用示例，设备主机指纹改为本地核验提示。贡献者姓名和私人邮箱改为稳定的匿名标识。代码接口和传感器数据格式不变。

`192.0.2.0/24`、`198.51.100.0/24` 和 `203.0.113.0/24` 中的地址仅供说明，不能用于连接实际设备。部署时从自己的私有配置读取地址，并把主机指纹与自己的可信 `known_hosts` 记录比较；不得关闭 SSH 主机身份核验。

真实采集样本使用通用房间/设备标识，只含低分辨率热阵列和环境/声音统计量，没有原始声音、参与者姓名、学号、邮箱或个人轨迹。样本仍包含时间与人数场景标签，属于房间整体数据，不能据此宣称所有情形均无法重新关联参与者。未来采集内容须再次审查后才能提交。

海报的 PDF 和 PowerPoint 元数据使用通用导出器名称，成员栏为占位符。历史文件版本经 Gitleaks 和额外身份信息检查，没有发现匹配常见格式的真实令牌、云端访问密钥或私钥；自动检查不能保证识别所有敏感信息。

运行 `python scripts/check_publication_privacy.py` 检查当前跟踪文件。CI 同时执行该检查及其回归测试。该检查不替代完整历史扫描、人工审查或部署安全检查。

原私有仓库有 16 个已关闭 PR。GitHub 的 PR 引用和旧提交缓存不能通过普通分支推送彻底清除，因此不能仅清理分支后就把原仓库公开。建议将此候选版本发布为独立公开副本，原仓库继续保持私有；不要把旧仓库历史再次合并或推入公开版本。

继续开发时，应使用 GitHub 提供的 `noreply` 提交邮箱，并避免在提交说明、Issue、PR、CI 日志或附件中写入私人资料。敏感配置、完整采集归档及原始私有历史备份应保存在公开仓库之外。

参考：[GitHub 删除敏感历史的说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。
