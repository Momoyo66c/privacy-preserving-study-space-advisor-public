- 日期：2026-07-18
- 状态：生效

## D-005：树莓派连接作为继续执行门禁

- 日期：2026-07-18
- 状态：生效
- 决策：继续执行前先尝试 SSH 重连。连续重试仍失败时，停止当前后续阶段并停用自动任务。
