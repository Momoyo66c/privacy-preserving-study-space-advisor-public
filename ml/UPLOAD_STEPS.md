# How to upload this package to GitHub

Recommended branch name:

```text
module2/edge-ml-rule-model
```

Recommended source branch:

```text
main
```

Use `module1/hardware-foundation` as the source only if your teammates confirm that the final `windows.jsonl` interface has not been merged into `main` yet.

The files in this package are arranged with repository-relative paths. Copy the `edge/ml/` folder from this package into the repository root, replacing the current placeholder `edge/ml/README.md`.
